# Security Policy

## Supported versions

Security fixes are made for the latest plugin release.

| Version | Supported |
| --- | --- |
| 0.3.x | Yes |
| 0.2.x and earlier | No |

## Reporting a vulnerability

Please report suspected vulnerabilities through a [private GitHub security advisory](https://github.com/ssauma/ai-safe-driver/security/advisories/new). Do not open a public issue containing vulnerability details.

Include the affected host and plugin version, a minimal reproduction, the security impact, and any suggested mitigation. Remove credentials, tokens, private conversation text, and unrelated personal data. Do not test against systems or data you do not own or have permission to use.

The maintainer will aim to acknowledge a report within seven days, confirm whether it is accepted, and coordinate disclosure after a fix is available. If private vulnerability reporting is unavailable, use the [security contact-request form](https://github.com/ssauma/ai-safe-driver/issues/new?template=security_contact.yml). It creates a public issue titled `Security contact requested` without vulnerability details. The maintainer will create a draft security advisory, add the reporter as a collaborator, and continue there before any details are shared.
